# 生物单位适配

本分支与[通用风格指南](../UNIT_MODELING_STYLE.md)共同使用。它把 M1A1 的“结构可信、轮廓优先、平涂块面、细节克制”迁移到动物、怪兽、虫类、人形和飞行生物。

生物巢穴、孵化设施等活体建筑同时读取[建筑分支](BUILDINGS.md)：本分支负责组织、分面与形变，建筑分支负责固定职能、地基、占地、产出通道及状态。

**状态：这是迁移标准与制作建议，不是已有生物成品的验收报告。** 首个生物单位需要验证视觉、形变和引擎接入，再决定哪些做法成为补充基准。

## 1. 保持生命感，不给生物套坦克外壳

| 共享原则 | 在生物上的含义 | 不应机械照搬的案例属性 |
| --- | --- | --- |
| 结构可信 | 骨架、肌肉体积、关节与支撑方式有逻辑 | 平直车体和装甲板分区 |
| 轮廓优先 | 物种／角色、头尾方向、体态和附肢可辨 | 低矮坦克的长宽高比例 |
| 大块面 | 用宽面概括头骨、胸腔、肩背、骨盆和主要肌群 | 把柔软组织都切成独立硬盒 |
| 色块克制 | 腹背差异、甲壳、口鼻、眼、角等有颜色职责 | 全身沙色或金属高光 |
| 动作有因果 | 支撑相、重心转移、呼吸、扑翼、尾随 | 禁止全部上下起伏，或用履带相位控制步态 |

“低模生物”不是随便减面后的写实扫描，也不是随机彩色三角拼接。它应当在很少的体积和色区里保留生命结构。

## 2. 灰模：先骨架，再肉体，再表面

### 2.1 定义运动结构

制作前写出：

- 身体主轴、头颈连接、胸腹与骨盆的关系。
- 肢体数量、主要关节、足型与通常的支撑姿态。
- 运动方式：步行、奔跑、爬行、跳跃、扑翼、游动或其他。
- 三至五个识别锚点，例如长口鼻、隆起肩背、特定角形、粗尾根、展开的翼形。
- 柔软、坚硬和可伸展部分分别在哪里，哪些地方必须连续形变。

虚构生物可以有非现实结构，但仍需在自身设定里一致：附肢从哪里生长、哪里承重、怎样弯曲、力量怎样传递。

### 2.2 用连贯体积，不用一串球或盒子交差

粗略球体、椭球或楔体可以用于起稿。进入成型时，要把头颈、肩胸、腹背、臀腿连接成有意设计的轮廓和体积过渡。

- 头部优先建立头骨、口鼻、下颌、眉弓或耳根，不先刻牙齿。
- 胸腔与骨盆应有各自的方向和宽高关系，不以一根均匀圆筒代替全身。
- 腿段反映关节与受力方向；从侧面核对膝、踝、跗部等关系，不能把后腿所有弯折都当“反向膝盖”。
- 尾巴从有厚度的尾根过渡到尾端，不像单独插上的细棒。
- 角、耳、鳍、爪和翅膀先看外轮廓与着生点，再考虑局部细节。

## 3. 分面与拓扑

### 3.1 让切面跟着解剖体积走

将主要体积划分成数量有限、方向明确的宽面：头的额侧面、颧部和下颌；胸背的肩线、侧胸和腹面；骨盆与大腿的前侧、外侧和后侧。

通过截面大小、朝向和疏密变化表达肌肉与骨点，不靠满身起伏小面表达“写实”。大面之间有必要的过渡；大块面不等于把所有区域做成同样大的方格。

硬质甲壳、角和爪可以比皮肤拥有更清楚的硬边。柔软组织仍保持块面感，但过渡要解释连续体积，而不是制造装甲板般的缝隙。

### 3.2 先验证形变方案

当前 M1A1 使用的是刚性 piece 层级。它不能直接证明本项目已经支持连续皮肤的骨骼蒙皮。开始大量细化前，按[Recoil 资产流程](RECOIL_PIPELINE.md)核对目标链路：

| 路线 | 适用对象 | 制作重点 |
| --- | --- | --- |
| 刚性分段 | 昆虫硬节、机械生物、明确硬壳或风格化分节角色 | 枢轴、关节遮挡和最大活动角度 |
| 连续皮肤蒙皮 | 需要柔软连续变形的兽类、人形、颈腹等 | 有效蒙皮导出、权重、关节环线、法线与动作验证 |
| 混合 | 皮肤主体加甲壳、义体或装备 | 各部分使用正确运动方式，并校验连接处 |

GLB 格式本身能表示蒙皮，不等于当前生成器或游戏接入链已经输出并播放它。链路未验证时先做一个关节的最小原型；如果只能交付刚性分段，要明确说明视觉与运动限制，不能把近似方案冒充完整蒙皮。

### 3.3 关节处的面数是功能预算

- 肩、肘、髋、膝、踝、颈和尾根按实际动作范围安排拓扑，避免长瘦三角形跨越关键弯折。
- 蒙皮模型在弯曲、伸展和扭转下检查塌陷、尖刺、体积丢失与法线跳变。
- 刚性模型在最大弯曲角度检查露缝和穿插；优先将分界放在天然硬节或能合理遮挡的位置。
- 平涂色区和硬边法线不要求断开可见皮肤；需要拆分渲染顶点时仍保持正确的几何连续性和权重关系。
- 小幅局部平滑可用于必要的形变连续性，但主体仍要保留与项目相容的宽面语言。

## 4. 按生物类别提炼特征

| 类别 | 必须先读清的体积与轮廓 | 可归纳的细节 |
| --- | --- | --- |
| 四足兽 | 头口鼻、肩背、胸腹收束、臀腿、足型、尾根 | 毛发并成少量簇，肌肉并成主群，细爪按视距取舍 |
| 人形／双足 | 头身比例、肩胯关系、手足、站姿、主要装备 | 手指与面部五官按角色需求合并，不默认刻全套微细节 |
| 昆虫／节肢 | 头胸腹、足的数量与节律、触角、口器、主要壳片 | 甲壳花纹与小硬毛用大色区或少量几何表示 |
| 爬行／甲壳生物 | 身体主轴、背甲外形、头颈、肢体着生、尾部变化 | 鳞片归成大甲区与少量轮廓鳞，不逐片铺满 |
| 鸟／翼兽 | 胸腔、翼根、翼展、主翼指／羽组、尾翼 | 羽毛归成几组宽楔面，翼膜按可变形的大面处理 |
| 水生／蛇形 | 头身关系、主曲线、鳍形或腹侧、尾端推进结构 | 用截面变化与宽色带代替密集表皮细节 |

关键部位可以被适度强化以保住正常视距下的可读性。增大眼或爪之前，先确认这种强化符合角色，不自动把所有生物变成同一种萌化比例。

## 5. 毛发、鳞片、牙齿和软组织

### 毛发与羽毛

用外轮廓和成组方向说明质感：一撮肩毛、几块尾羽、少量鬃毛楔形。先保留毛／羽的流向与大小层次，再决定是否需要纹理。大量细毛片、透明叠层和逐根几何通常会造成噪声与额外显示成本。

### 鳞片与甲壳

区分甲壳外轮廓和表面小鳞。前者可以是几何与分节，后者多数合并成大色区。沿背脊或尾部的少量大鳞可以作为锚点，身体全部区域不必均匀重复。

### 牙、爪、角

先保住嘴形和主咬合轮廓；只有看得见、会影响角色辨识的牙齿才单独建模。大爪和角使用简洁截面与有变化的锥度，避免从根到尖等粗或随意插接。

### 眼、口腔和皮肤

眼和口鼻提供焦点，不抢走整个身体。口腔采用受控深色，避免张嘴后出现空洞穿帮；皮肤依靠体积与少量色区表达，不默认使用毛孔、照片、全身湿亮高光或强烈次表面效果。

## 6. 配色与机械单位统一的方法

共享的是颜色层级和表面克制程度，而不是同一组 RGB。

- 从主体皮肤／甲壳色、腹背变体、深色口鼻／关节、骨角色、少量眼色开始。
- 腹背差异或宽条纹沿解剖分区组织，避免随机给每个面换色。
- 阵营识别可通过有限的天然斑纹、背甲区域、装具或徽记实现；设计时检查正常游戏俯视下能否看到。
- 眼、毒囊或特殊器官的发光若是角色要求，可以使用，但把范围和强度控制在功能焦点，不用满身发光掩盖轮廓。
- 与 M1A1 并排时比较大面与小面的比例、颜色焦点数量、反射强弱，而不是比较是不是同样沙黄。

## 7. 动作中的生命感

### 7.1 用支撑和相位组织动作

四足或双足步态先画出支撑相与摆动相，再安排躯干起伏、头颈平衡和尾部跟随。移动速度改变时考虑步频、步幅或状态切换，避免模型跑得很快而脚还在原地慢划。

“脚底不滑”不仅是脚的动画问题，也涉及角色实际位移。检查起步、停步、转向、变速和坡地；跨步期间允许身体合理起伏，不把 M1A1 的车体稳定规则变成生物僵直规则。

### 7.2 少量有原因的次级动作

呼吸来自胸腹，尾巴跟随转向和重心，耳或翅翼的动作服务于感知与姿态。次级动作与主动作有层级，不让头、胸、腿、尾全部以相同幅度和相位循环摆动。

扑翼、爬行、游动或跳跃按各自的支撑／推进机制设计。攻击先确认发力部位与接触／发射点，再增加蓄力、挥击和回收；不把全身振动当作通用攻击反馈。

## 8. 两个迁移示例

**四足装甲兽**：保留厚重肩背、短而有力的口鼻、四肢支撑和粗尾根；背甲归纳成少量大壳片，腹部保留连续体积，脚爪只保留大形；主色与骨角、口鼻分层。它应有兽类步态，而不是把坦克车体接上四条棍子。

**六足甲虫**：先明确头胸腹、六足着生点和张开的支撑范围；壳片用大面，腿按硬节分件，口器和触角作为少量辨识点。刚性分节较适合现有 piece 思路，但仍需验证脚的接触、转向和每个关节枢轴。

两者都是设计示例，不代表资源已制作、动画已接入或已通过测试。

## 9. 分支验收补充

- [ ] 灰模能辨认物种／角色、朝向和支撑方式，而不只依靠颜色。
- [ ] 头颈、胸腹、骨盆和附肢连接可信，分面跟随主要体积。
- [ ] 毛羽、鳞片、牙爪已按视距归纳，没有把表面做成均匀噪声。
- [ ] 柔软和硬质区域使用合适的形变／分件方案；已注明链路验证状态。
- [ ] 最大动作幅度下关节不明显裂开、塌陷或穿插，脚／翅／尾的动作有因果。
- [ ] 正常视距与 M1A1 同屏时，细节密度和表面表达属于同一风格。

最终验收仍使用通用指南的 G1–G4；生物分支不能跳过目标引擎的实际检查。
